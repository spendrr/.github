# Spendrr

A Bitcoin wallet for people who don't want to learn how Bitcoin works. Self-custodial, instant and cheap payments, no jargon. Runs in the browser and installs as an app.

**[Open the wallet](https://spendrr.app)** · **[What is it?](https://spendrr.app/learn/en)** · **[Network status](https://spendrr.app/status)**

## Open source

The code is public under the AGPL-3.0 in **[spendrr/web](https://github.com/spendrr/web)**.

- **Verify it.** The build is reproducible: you can rebuild a tagged release and compare every file `spendrr.app` serves with your build, byte for byte. A public workflow does the same every hour. Steps are in [VERIFY.md](https://github.com/spendrr/web/blob/main/VERIFY.md).
- **Report a vulnerability** privately through [the repository's security advisories](https://github.com/spendrr/web/security/advisories/new). Scope and what to expect: [SECURITY.md](https://github.com/spendrr/web/blob/main/SECURITY.md).
- **Issues are welcome**, pull requests are not accepted for now.

Real money on Bitcoin mainnet. No independent security audit yet.
